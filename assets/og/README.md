# Fonts for the share image

`NotoSansJP-400.ttf` / `NotoSansJP-700.ttf` contain only the characters used in `src/app/opengraph-image.tsx` (Google Fonts `text=` subset, retrieved 2026-11-20). Noto Sans JP is distributed under the SIL Open Font License (see `public/fonts/`).

If you change the text in the share image, fetch the subset again with the new characters, or missing glyphs will render as blank boxes.
